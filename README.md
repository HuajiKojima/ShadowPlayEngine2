# Shadow Play Game Engine

![License](https://img.shields.io/github/license/HuajiKojima/ShadowPlayEngine2.svg)
![Issues](https://img.shields.io/github/issues/HuajiKojima/ShadowPlayEngine2.svg)

This is a game engine project what based on vulkan and OpenGL. 
This project comply with the MIT License, it means that you can make your own games by this engine for free and you can sell your games or project without any license fee or other something.

I'm really welcome that you want to contribute your code or discover the problem and want to solve them, please watch the project wiki, the wiki has the way to build this project on different platforms.

This project use some 3rd vendor library, thanks for these creators and contributers.

Enjoy it!
